# Kick strength data logger

[View full project on microbit\.org](https://microbit.org/projects/make-it-code-it/kick-strength-data-logger)

To code this project yourself, right click on the background of the workspace and choose ‘delete all blocks’, then follow the coding video below. You can find the `forever` and `on start` blocks in the `Basic` section.

### What is it?

Use your BBC micro:bit to improve your game by collecting sports science data on the strength of kicks or racket strokes.

### How it works

This project uses the micro:bit’s [accelerometer sensor](https://microbit.org/get-started/features/sensors/#accelerometer) and [data logging feature](https://microbit.org/get-started/features/data-logging/) to log and store data on how hard you kick a ball, or hit a racket, over a short period of time. You can then study the data on a computer to improve your consistency or performance over time, in the same way sports professionals use data science to help improve their performance.

## Use as Extension

This repository can be added as an **extension** in MakeCode.

* open [https://makecode.microbit.org/](https://makecode.microbit.org/)
* click on **New Project**
* click on **Extensions** under the gearwheel menu
* search for **https://github.com/fredmcgee-sketch/kick-strength-data-logger** and import

## Edit this project

To edit this repository in MakeCode.

* open [https://makecode.microbit.org/](https://makecode.microbit.org/)
* click on **Import** then click on **Import URL**
* paste **https://github.com/fredmcgee-sketch/kick-strength-data-logger** and click import
