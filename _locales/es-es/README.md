# Registrador de datos de fuerza de patada

[Ver proyecto completo en microbit\.org](https://microbit.org/es-es/projects/make-it-code-it/kick-strength-data-logger)

Para codificar este proyecto tú mismo, haz clic derecho en el fondo del área de trabajo y elige ‘delete all blocks’, luego sigue el video de codificación a continuación. Puedes encontrar los bloques forever y on start en la sección Basic.  
  


### ¿Qué es?

Utiliza tu BBC micro:bit para mejorar tu juego recopilando datos de la ciencia del deporte sobre la fuerza de los saques o los golpes de raqueta.

### Cómo funciona

Este proyecto utiliza el [sensor acelerómetro](https://microbit.org/es-es/get-started/features/sensors/#accelerometer) del micro:bit y [la función de registro de datos](https://microbit.org/es-es/get-started/features/data-logging/) para registrar y almacenar datos sobre la fuerza con la que pateas una pelota, o golpeas una raqueta, durante un corto período de tiempo. A continuación, puedes estudiar los datos en un ordenador para mejorar tu regularidad o rendimiento a lo largo del tiempo, del mismo modo que los profesionales del deporte utilizan la ciencia de datos para ayudar a mejorar su rendimiento.

Visita la [página de proyectos en microbit\.org](https://microbit.org/es-es/projects/make-it-code-it/) para una descripción completa de este y otros proyectos.
