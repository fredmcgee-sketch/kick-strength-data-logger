# 踢球力度记录器

[View full project on microbit\.org](https://microbit.org/zh-cn/projects/make-it-code-it/kick-strength-data-logger)

To code this project yourself, right click on the background of the workspace and choose ‘delete all blocks’, then follow the coding video below. You can find the `forever` and `on start` blocks in the `Basic` section.

### 它是什么？

使用BBC micro:bit收集踢腿或挥拍的力度数据，提升您的比赛水平。

#### 介绍

https://www.youtube.com/watch?v=wCoDEYSLLmo

#### 编程指南

https://www.youtube.com/watch?v=XrY6yE0qwfw

### 工作原理

这个项目使用了micro:bit的[加速计](https://microbit.org/zh-cn/get-started/features/sensors/#accelerometer)和[数据记录功能](https://microbit.org/zh-cn/get-started/features/data-logging/)，记录下您在短时间内踢球或挥拍得多用力。 然后，您可以在电脑上研究这些数据，让动作发挥稳定，提高比赛表现，就像体育专业人士使用数据科学来帮助提升他们的表现一样。
