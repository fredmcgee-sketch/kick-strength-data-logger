# Cofnodydd data cryfder cic

[View full project on microbit\.org](https://microbit.org/cy/projects/make-it-code-it/kick-strength-data-logger)

To code this project yourself, right click on the background of the workspace and choose ‘delete all blocks’, then follow the coding video below. You can find the `forever` and `on start` blocks in the `Basic` section.

### Sut mae'n gweithio

Mae'r prosiect hwn yn defnyddio [synhwyrydd cyflymromedr](https://microbit.org/cy/get-started/features/sensors/#accelerometer) a [ a nodwedd cofnodi data](https://microbit.org/cy/get-started/features/data-logging/) micro:bit i logio a storio data ar ba mor galed ydych chi'n cicio pêl, neu'n taro raced, dros gyfnod byr o amser. Yna gallwch chi astudio'r data ar gyfrifiadur i wella'ch cysondeb neu berfformiad dros amser, yn yr un modd mae mabolgampwyr proffesiynol yn defnyddio gwyddor data i helpu i wella eu perfformiad.
