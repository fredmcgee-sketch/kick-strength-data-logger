### Como funciona:

Este projeto utiliza o [sensor de acelerômetro](https://microbit.org/pt-br/get-started/features/sensors/#accelerometer) e [recurso de registro de dados](https://microbit.org/pt-br/get-started/features/data-logging/) do micro:bit para registrar e armazenar dados sobre a força com que você chuta uma bola ou bate em uma raquete, ao longo de um curto período de tempo. Você pode então analisar os dados em um computador para melhorar sua consistência ou desempenho ao longo do tempo, da mesma forma que os profissionais do esporte utilizam a ciência de dados para ajudar a melhorar seu desempenho.
