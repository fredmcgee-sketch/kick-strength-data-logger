# Enregistreur de données de force de tir

[Voir le projet complet sur microbit\.org](https://microbit.org/fr/projects/make-it-code-it/kick-strength-data-logger)

Pour coder ce projet vous-même, cliquez avec le bouton droit de la souris sur l'arrière-plan de l'espace de travail et sélectionnez « Supprimer tous les blocs », puis suivez la vidéo de codage ci-dessous. Vous trouverez les blocs `forever (répéter indéfiniment)` et `on start (au démarrage)` dans la section `Basique`.

### Qu'est-ce que c'est ?

Utilisez votre BBC micro:bit pour améliorer votre jeu en collectant des données scientifiques sur la force des coups de pied ou des coups de raquette.

### Comment ça marche

Ce projet utilise [l'accéléromètre](https://microbit.org/fr/get-started/features/sensors/#accelerometer) du micro:bit et [la fonctionnalité de sauvegarde des données](https://microbit.org/fr/get-started/features/data-logging/) pour enregistrer et stocker des données sur la difficulté de frapper une balle avec le pied ou avec une raquette, sur une courte période. Vous pouvez ensuite étudier les données sur un ordinateur afin d'améliorer votre régularité ou vos performances au fil du temps, de la même manière que les professionnels du sport utilisent la science des données pour améliorer leurs performances.

Visitez la [page des projets sur microbit\.org](https://microbit.org/fr/projects/make-it-code-it/) pour une description complète de ce projet et bien d'autres.
