# 킥 강도 데이터 로거

[View full project on microbit\.org](https://microbit.org/ko/projects/make-it-code-it/kick-strength-data-logger)

To code this project yourself, right click on the background of the workspace and choose ‘delete all blocks’, then follow the coding video below. You can find the `forever` and `on start` blocks in the `Basic` section.

### 프로젝트 소개

BBC micro:bit 를 사용해 킥이나 라켓 스트로크의 강도에 대한 스포츠 과학 데이터를 수집하여 게임 실력을 향상시켜 보세요.

#### 소개

https://www.youtube.com/watch?v=wCoDEYSLLmo

#### 프로그래밍 가이드

https://www.youtube.com/watch?v=XrY6yE0qwfw

### 설명

이 프로젝트에서는 micro:bit 의 [가속도계 센서](https://microbit.org/ko/get-started/features/sensors/#accelerometer)와 [데이터 로깅 기능](https://microbit.org/ko/get-started/features/data-logging/)을 사용하여 짧은 시간 동안 공을 차거나 라켓을 치는 강도에 대한 데이터를 기록하고 저장합니다. 그러면 스포츠 전문가들이 데이터 과학을 활용해 성과를 개선하는 것과 같은 방식으로, 컴퓨터에서 데이터를 연구해 일관성이나 성과를 시간이 지남에 따라 개선할 수 있습니다.

Visit the [projects page on microbit\.org](https://microbit.org/ko/projects/make-it-code-it/) for a full description of this and other projects.
